About Project

System overview and technical specifications

SMSAM System v1.0

An autonomous monitoring and security solution built on the ESP32 ecosystem. Designed for real-time environmental tracking and visual surveillance with minimal infrastructure requirements.

Core Hardware

  • 🔹 ESP32: Central Controller
  • 🔹 ESP32-CAM: Video Streamer
  • 🔹 DHT22: Temp & Humidity
  • 🔹 HC-SR04: Proximity Radar
  • 🔹 PIR Sensor: Motion Detection

Software Stack

  • 🚀 Backend: Python / Flask
  • 🎨 Frontend: Vanilla CSS (Premium)
  • ⚙️ Firmware: C++ / Arduino IDE
  • 🌐 Protocol: HTTP / MJPEG

Project Objectives

The primary goal is to demonstrate how low-cost embedded systems can be leveraged to create professional-grade monitoring solutions. By integrating various sensors and a live video feed, SMSAM provides a comprehensive overview of machine or environment status in real-time.
